# Статус проверки alpha

Начальная публичная версия подготовлена из integration tree `fa9501f01b9576acb84b3351a7a325a0b2b21870` 15 ноября 2026. В исходники не включены лабораторные базы, ключи и история внутренних экспериментов.

На исходном integration tree пройдены по 162 теста workspace, Clippy с `-D warnings` и release-сборки под Windows 11 и Linux/WSL2. Один тест большого внешнего корпуса штатно ignored и запускается отдельно при наличии доверенных данных. Прогоны настоящего CLI выполнены также в Ubuntu 24.04 VM с собственным ядром 6.8.0-149.

Официальный genesis `minter-mainnet-5`, SHA-256 `906c2ab969389853247305b0930c92f5906dc1962cd3075832ca4d7ab0fe55a5`, содержит 127 580 513 байт app_state. На обеих ОС проверены семь штатных остановок при чтении, JSON/SHA и IAVL, отсутствие опубликованного head после остановки, повтор из той же базы и открытие до первого блока без исходного файла. Конечный AppHash `c88e583eecef3cb49965bb61fe35450c430cf6ae968fc09850d4ca670503620f` на H10 196 999 совпал с сохранённым Go-эталоном; доказательство IAVL проверено и сохранилось после открытия. Это не новая полная трасса Go-операций.

До публичной подготовки также пройдены импорт настоящего снимка, возобновление обязательной истории, экспорт, очистка и межпроцессное управление; есть mainnet-пилоты Windows/Ubuntu. Все 37 активных типов транзакций закреплённого Go имеют реализации и тестовые векторы. Наличие обработчиков не доказывает полную историческую совместимость.

Production WebView GUI проверялся на Windows 11 и Ubuntu 24.04 в контейнере с Xvfb/WSL2. Это не проверка установщика на чистой графической Ubuntu. Публичная CI проверяет собственный commit и публикует отдельный результат сборки.

При подготовке публичного дерева 15 ноября 2026 повторно прошли Rust formatting, frontend formatting, Svelte/TypeScript без ошибок и предупреждений, frontend production build, GUI Clippy и locked production build под Windows. Это локальные проверки; результат hosted CI для публичного commit виден отдельно во вкладке Actions.

Аудит Rust lockfile завершился с кодом 0, сохранив предупреждения о неподдерживаемых `paste`, `serde_cbor`, `proc-macro-error`, `zbus_names`, `zvariant` и `zvariant_derive`, а также [предупреждение о soundness в glib 0.18.5](https://rustsec.org/advisories/RUSTSEC-2024-0429/). Npm сообщает две проблемы низкой серьёзности в цепочке инструмента сборки `@sveltejs/vite-plugin-svelte` → `deepmerge`: [GHSA-gcqx-w48m-w2h4](https://github.com/advisories/GHSA-gcqx-w48m-w2h4). Они остаются открытыми; исправления зависимостей требуют отдельной проверки. Аудит не является доказательством отсутствия остальных дефектов.

Открыто: остальная историческая сверка и протокольная приёмка, часть отмены внутренних циклов genesis и ABCI shutdown, автоматическая публичная доставка доверенных точек, чистые установки/обновления, 14 суток непрерывного mainnet-пилота и допуск валидатора. Alpha рассчитана на тестирование обычной ноды и инструментов разработчика.
