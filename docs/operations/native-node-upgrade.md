# Обновление существующей нативной ноды

Эта инструкция относится к `minter-mainnet-5`. При открытии базы от ранней сборки новая нода может потребовать однократно восстановить историю валидаторов:

```text
upgrade this database once with --checkpoint and --checkpoint-sha256 to restore its validator history
```

Для такого обновления нужен исходный доверенный **нативный checkpoint**, с которого начиналась эта база: `manifest.json`, `state.pb`, `blocks.pb` и `snapshot.zlib`. Возьмите SHA-256 манифеста из проверенной записи исходного импорта.

1. Остановите ноду и сохраните холодную копию её каталога состояния. Сохраните прежний бинарник для восстановления.
2. Посмотрите базовую высоту исходного checkpoint и запишите текущие высоту, AppHash, `earliestHeight` и `keepIavlVersions`:

   ```text
   minterctl checkpoint status --db "./state"
   minterctl iavl history --db "./state"
   ```

3. Подставьте в команду сохранённую текущую высоту `HEIGHT`, прежнее значение `KEEP` и доверенный SHA-256 исходного манифеста `SHA256`. Весь пакет должен соответствовать базовой высоте из `checkpoint status`.

   ```text
   minterd native-sync --db "./state" --checkpoint "./checkpoint" --checkpoint-sha256 SHA256 --blocks "./checkpoint/blocks.pb" --through HEIGHT --keep-iavl-versions KEEP
   ```

4. После успеха журнал содержит `Restored Tendermint validator history from … through …`, а итоговый JSON — `"blocks":0`. Повторите `iavl history` и сравните все четыре ранее записанных значения.
5. Запустите обычную команду синхронизации. После завершённого обновления параметры `--checkpoint` и `--checkpoint-sha256` для повторного открытия базы не нужны.

Обновление читает сохранённые блоки и изменения валидаторов, проверяет их связь с исходным checkpoint и текущим курсором и дополняет индекс. Оно сохраняет уже вычисленное состояние приложения. Если команда завершилась ошибкой, сохраните журнал и холодную копию до выяснения причины.

Новая база, созданная текущей версией, получает индекс при обычной синхронизации. Эти действия нужны для прежних баз без индекса.
