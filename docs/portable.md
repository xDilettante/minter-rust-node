# Minter Rust Node: экспериментальная сборка

Это unsigned portable-сборка для тестирования обычной ноды. Распакуйте архив целиком: `minter-desktop`, `minterd` и `minterctl` должны оставаться рядом. На Windows имена заканчиваются на `.exe`.

Версия исходников и инструменты записаны в `build-info.json`, контрольные суммы файлов — в `SHA256SUMS`, лицензии — в `licenses/`. [Исходный репозиторий и CI](https://github.com/xDilettante/minter-rust-node).

## Запуск

Windows 11 x64: запустите `minter-desktop.exe`. Нужны WebView2 и Microsoft Visual C++ Runtime x64.

Ubuntu 24.04 x86_64: запустите `./minter-desktop` в графическом сеансе. Нужны системные библиотеки Tauri: GTK 3, WebKitGTK 4.1, Ayatana AppIndicator. [Требования Tauri](https://v2.tauri.app/start/prerequisites/).

Для CLI выполните из каталога распаковки:

```sh
./minterd --help
./minterctl --help
```

В PowerShell используйте `./minterd.exe` и `./minterctl.exe`.

В GUI выберите полную или лёгкую ноду, каталог данных и источники доверия. Полной ноде нужен проверенный checkpoint-пакет, SHA-256 его `manifest.json` и пиры; лёгкой — независимые RPC и доверенная точка. Публичная автоматическая доставка ещё готовится. Без этих входов первоначальная синхронизация не настроена.

Путь CLI для полной ноды из снимка:

```sh
./minterd native-sync \
  --db ./node/state \
  --checkpoint ./checkpoint \
  --checkpoint-sha256 TRUSTED_MANIFEST_SHA256 \
  --peer NODE_ID@HOST:26656 --follow \
  --storage-profile full \
  --p2p-listen 127.0.0.1:26656 \
  --api-listen 127.0.0.1:8841
```

Замените значения-заполнители проверенными данными. В PowerShell запишите команду одной строкой с `./minterd.exe`. При повторном запуске используйте тот же каталог базы и сетевые настройки. Ctrl-C завершает CLI штатно.

## Ограничения alpha

Полная историческая совместимость, длительная mainnet-приёмка, допуск валидатора и чистые установки ещё не завершены. Начальная загрузка снимка позволяет обойтись без всей предыдущей истории; архивный режим сохраняет историю только с доступной точки начала. Лёгкий клиент проверяет поддерживаемые заголовки и доказательства, его источники доверия задаёт оператор.

[Подробный статус проверки](docs/validation.md), [техническая справка](TECHNICAL.md), [описание GUI](desktop/README.md). Эта сборка не является стабильным официальным выпуском Minter.
